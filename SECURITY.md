# Security policy

Do not report vulnerabilities in a public issue.

Use a [private GitHub security advisory](https://github.com/Benmore-Studio/automated-qa/security/advisories/new).
Include the affected version, exact command and exit code, what input an attacker
controls, and the smallest reproduction that contains no credentials or private
application data.

Never attach cookies, tokens, credentials, payload values, private source, or
unreviewed screenshots from `.verify/capture/`.
